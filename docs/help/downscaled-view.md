# Downscaled view

A sharper picture without anything falling off the screen: the game window is made larger than the monitor
(for example 2x) and kept out of sight, and an overlay shows it scaled down. Windows only.

1. Select the game window, open the **Downscale** tab.
2. Choose the monitor, the **Sharpness** (1.5x to 4x) and the **Picture shape**.
3. **Start downscaled view.** Stop with **Stop** or **Ctrl+Alt+D** (works from anywhere).

- It only adds detail if the game renders at its window size (RPCS3 and most emulators do).
- Keyboard and gamepad keep going to the game; mouse clicks on the picture are forwarded (untick that for
  games that read raw input).
- It costs GPU power and video memory. Windowed and borderless games only.
