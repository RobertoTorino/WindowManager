# Focus and hotkeys

A game like Tekken 7 keeps the keyboard. While a game runs, the stats bar shows **Focus: game / app / other**,
and two keys work from anywhere (Windows only):

| Key | What it does |
|---|---|
| **F1** | Switch between the game and this app. |
| **F2, twice within 2 s** | Terminate the game, like **Shutdown**. |
| **Ctrl+Alt+M** | Free the mouse from a game that holds it, and bring this app to the front. |

- If the game grabs the focus straight back, the app goes **mouse only**: its buttons work with the mouse
  while the game keeps the keyboard.
- One monitor: **View > Window opacity** makes the app see-through while a game runs, and minimising it
  gives the small **floating bar**.
- Change the keys under *View > Focus switch hotkey...* and *Terminate hotkey...*.
