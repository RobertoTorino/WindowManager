# Getting started

WindowManager takes control of the windows of a game or emulator: true borderless full screen, exact sizes,
moving between monitors, a picture that fits the monitor, a sharper downscaled view, and the PC's display, GPU
and power settings per game. On Linux (beta) it works for Steam games under Proton: see [Linux](linux.md).

These pages have the highlights. Everything in full, with pictures, is in the
[online wiki](https://robertotorino.github.io/WindowManager/) (also *Help > Online wiki*).

## The first five minutes

1. **Add a game.** Steam games are already in the dropdown. For anything else: **Add game...** (Ctrl+O) and
   pick an `.exe`, `.bat` or `.cmd`.
2. **Start it.** Click **Start**. Already running? Pick the game and press **Scan**.
3. **Let it fit.** The *Fit window to monitor* popup opens; **Apply correction** makes the picture fill the
   monitor. See [Fit to monitor](fit-to-monitor.md).
4. **Select the window.** The green, bold row in the table is the window every button acts on.
5. **Adjust** with the buttons and tabs. A **green** button means that state is on.
6. **Save the result.** *Position & Size* > **Save position**; **Force saved settings** applies it again.

## Good habits

- **Laptops:** play plugged in, and set games to *High performance* on the **GPU & Power** tab.
- **A game that keeps the keyboard:** **F1** switches between the game and this app. See [Focus and hotkeys](focus.md).
- **Something wrong?** *File > View logs...* (Ctrl+L). See [Logs and troubleshooting](logs-and-troubleshooting.md).
