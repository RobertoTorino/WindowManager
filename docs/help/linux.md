# Linux (beta)

On Linux the app works for Steam games under Proton, in Bazzite's Desktop Mode (KDE Plasma).

- **Works:** Steam games found and started through Steam, Scan, Focus, Shutdown, monitor moves, sizes,
  **True Borderless FS** (the desktop's own full screen), Topmost, snapshots.
- **Not yet:** downscaled view, Display tab, game info overlay, HelixSR, Layered / No Activate, Gaming Mode.
- Only X11 (XWayland) windows are seen. Many Proton windows have a fixed size: use **True Borderless FS**.
- There is no download yet: it is built from source in a distrobox.
