# Logs and troubleshooting

*File > View logs...* (Ctrl+L) shows the application log and one log per game. Every action is logged with
its result; start with the last `WARN` or `ERROR` lines.

| Symptom | What to try |
|---|---|
| Table is empty after Start | Press **Scan**. |
| Buttons do nothing to the game | The game runs as administrator: run WindowManager as administrator too. Or the active row is a helper window: click the game's real window. |
| Window jumps back | Turn on **Stability**, or set the game's own window settings to the monitor. |
| Game runs slowly | Check the orange warning on the stats bar: plug in, and set the game to *High performance*. |
| *FPS needs admin* | Add your account to *Performance Log Users* (see [Game stats](game-stats.md)). |
| The app's keys do nothing | The game keeps the keyboard: press **F1** (see [Focus and hotkeys](focus.md)). |
| Mouse stays locked in the game | **Ctrl+Alt+M**. |
