# Shortcuts

| Keys | Action |
|---|---|
| F1 | Open this help. While a game runs: switch the focus between the game and this app (works from the game; *View > Focus switch hotkey...*). |
| Ctrl+O | Add game... |
| Ctrl+S | Toggle the game between monitor 1 and monitor 2 |
| Ctrl+F | Fit window to monitor... |
| Ctrl+L | View logs... |
| Ctrl+M | Move this app's window to the other monitor |
| Ctrl+B | Switch to the floating bar |
| Ctrl+Alt+D | Stop the downscaled view (works from anywhere). Windows only. |
| Ctrl+Alt+M | Release the mouse from a game that holds it, and bring this app to the front (works from anywhere). Windows only. |
| F2, twice within 2 s | While a game runs: terminate it, like Shutdown (works from the game; *View > Terminate hotkey...*). Windows only. |
| Ctrl+Q | Exit |
