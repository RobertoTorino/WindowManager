# Window controls

All of these act on the **active window**: the green, bold row in the table. The table follows the game by
itself; **Scan** reads it again and picks the best window.

| Button | What it does |
|---|---|
| **Monitor 1 / 2** | Move the window to that monitor (Ctrl+S toggles). |
| **Stability** | Puts the window back when the game moves or resizes it. |
| **Focus** | Brings the game to the front. |
| **Reset All** | Normal window styles again, saved position forgotten. |
| **Shutdown** | Terminates this session's game and loaders (asks first). |

## Tabs

- **Window:** *Windowed*, *True Borderless FS* (covers the whole monitor), *Fit Screen* (taskbar stays
  visible), *Fit to monitor...*; Topmost and the other extended styles (green = on).
- **Position & Size:** arrow pad and width/height by *Step*, **Set size**, overscan, **Save position** /
  **Force saved settings**.
- **Presets:** one click sets a size from 1920x1080 to 7680x4320.
- **Capture:** PNG screenshots, one or a burst; **Open folder** shows them.
